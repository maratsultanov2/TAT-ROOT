# TAT Defense Module

## Описание
Пятиуровневая система защиты TAT для обнаружения аномалий и управления флудом.

## Компоненты
1. **Дивергенция** — структурный контроль.
2. **Гармония** — контроль согласованности.
3. **Временной анализ** — обнаружение динамических аномалий.
4. **Перенаправление флуда** — управление шумовыми потоками.
5. **Шифрование графов** — защита структуры.

## Результаты
- Лучший F1 на синтетических данных: **0.757** (взвешенное голосование).
- Точность (Precision): **1.000** (без ложных срабатываний).

## Настройка
- Для высокой точности → взвешенное голосование.
- Для высокой полноты → фиксированные пороги.
