Многоуровневая система обнаружения аномалий и управления флудом для систем на основе TAT.

## Возможности
- Обнаружение структурных сбоев (дивергенция)
- Отслеживание потери согласованности (гармония)
- Выявление временных аномалий
- Перенаправление шумовых потоков
- Шифрование и смещение графов

## Настройка
Два режима работы:
- **Высокая точность** — минимум ложных срабатываний.
- **Высокая полнота** — максимум обнаруженных аномалий.

|---|---|---|---|---|

Вариант с взвешенным голосованием даёт идеальную точность (без ложных срабатываний) при хорошей полноте.

## Где использовать TAT Defense

TAT Defense предназначен для обнаружения **структурных разрывов** — не статистических выбросов, а нарушений порядка, иерархии или согласованности.

### Пример 1: Иерархические аномалии (синтетические данные)

Данные состоят из упорядоченных блоков (например, категории, шаги, модули). Аномалия = перестановка блоков или нарушение порядка.

- **TAT Defense:** F1 = 0.52
- **Автоэнкодер:** F1 = 0.08

TAT явно выигрывает, потому что обнаруживает разрыв в структуре, а не отклонение в значениях.

### Пример 2: Корреляции временных рядов (данные, похожие на NASA)

Данные состоят из коррелированных временных рядов. Аномалия = один канал нарушает корреляцию с другими.

- **TAT Defense:** F1 = 0.05
- **Автоэнкодер:** F1 = 0.63

Здесь выигрывает автоэнкодер, потому что аномалия является статистическим выбросом в ошибке реконструкции. Это область, где TAT не предназначен для конкуренции.

### Когда выбирать TAT Defense

- **Используйте TAT**, когда аномалии связаны с **порядком, иерархией или последовательностью** (логистика, поток диалогов, производственные шаги, структура кода, таксономии знаний).
- **Используйте автоэнкодеры**, когда аномалии связаны с **редкими значениями или статистическими выбросами** (финансовое мошенничество, скачки датчиков, контроль качества по значениям).

TAT не является универсальным детектором аномалий. Это специалист по структурным разрывам.
