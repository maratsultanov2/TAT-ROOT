# TAT Glossary

## TAT-T Crystal
Three-layer architecture with configurable phase shifts for DNA/RNA/Protein layers. See [TAT-T Crystal documentation](docs/en/TAT-T_CRYSTAL_PHASE_SELECTION.md).

## Phase Scan
Grid search over phase values to find optimal configuration for coherence. Used in TAT-T Crystal selection.

## Divergence Trace
`Position - Coherence` — leading indicator of memory drift. Used across TAT-7 and TAT-T.

## Harmony Gate
Structural veto: if harmony is silent, consolidation is forbidden. Weight = 2.0.

## Kettle Principle
Sufficiency as energy efficiency — no need to boil water for tea.

## Operational Envelope
93–96% — the working range of the system.

## Mirror Timestamp
`DD.MM.YYYY / YYYY.MM.DD` with axis of symmetry for robustness.

## Chunk Carousel
Memory management without discard/defer.


## Adaptive Phase
A phase shift parameter that is learned during training. In TAT-T Crystal, the phases of DNA, RNA, and Protein layers are trainable, allowing the system to self‑calibrate to the data structure. See the [Financial Case Study](docs/en/TAT-T_CRYSTAL_FINANCIAL_CASE.md) for an example.
