## 1. Neuroscience Foundation

**Terminal lucidity** is a documented phenomenon in neuroscience: patients with severe dementia or prolonged coma experience a brief, spontaneous recovery of cognitive functions — memory, speech, self-awareness — shortly before death. The window lasts minutes to hours, then closes permanently.

Key characteristics:
- **Spontaneous onset** — not triggered by external intervention
- **Full cognitive recovery** — the person becomes "themselves" again
- **Brief duration** — the window closes irreversibly
- **Precedes terminal decline** — lucidity is followed by death

### Lucidity Window Duration (LWD)
The number of consecutive steps with divergence < 0.1. Measures the stability of the high-coherence state.

### Apogee/Perigee Ratio (APR)
The ratio of time spent in apogee (divergence < 0.1) to total cycle time. Used to assess the effectiveness of phase-stabilising mechanisms.

### Structural Resilience Index (SRI)
The ability of the structural memory holder to return the system to baseline after perturbation. Measured as the recovery time from peak divergence to stable state.
