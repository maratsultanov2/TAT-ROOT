# TAT Semantic Notation Guide

## Назначение
Формальный язык описания архитектурных, физических и операциональных состояний TAT.

## Основные символы
| Символ | Назначение | Пример |
|--------|------------|--------|
| `/` | Семантический разделитель (AND/OR/THRESHOLD по контексту) | `DNA/RNA/Protein`, `silence/signal` |
| `//` | Взаимодействие и переход на второй слой | `DNA//RNA` |
| `///` | Взаимодействие и переход на третий слой | `DNA//RNA///Protein` |
| `→` | Переход (направленный) | `sync → async` |
| `↦` | Отображение (преобразование) | `div/harm ↦ signal` |
| `~` | Приближение, аналогия | `signal ~ F` |
| `#` | Идентификатор, метка | `L#20`, `t#2026-07-17` |
| `@` | Привязка к контексту | `mode@sync`, `anchor@L20` |
| `&` | Конъюнкция (одновременное присутствие) | `DNA & RNA` |
| `_` | Активное состояние (подчёркивание) | `sync_` |

## Правила интерпретации
- **AND (одновременное):** слои и компоненты (`DNA/RNA/Protein` — все три существуют вместе).
- **OR (выбор режима):** состояния (`sync/async` — система может быть в одном из двух).
- **THRESHOLD (результат сравнения):** пороги (`silence/signal` — определяется значением сигнала).

## Вложенность
- Слеш может быть n-арным: `A/B/C`.
- Допустима группировка скобками: `(DNA/RNA)/(Protein/Memory)`.

## Примеры
- `div/harm ↦ signal` — из пары дивергенция/гармония получается сигнал.
- `sync_ → async_` — переход из активного синхронного в асинхронный режим.
- `L#20@anchor` — точка L=20, помеченная как якорь.

## Связь с математикой
Слеш `/` не является арифметическим делением. В математических формулах используется LaTeX: `\frac{\partial F}{\partial T}`.
