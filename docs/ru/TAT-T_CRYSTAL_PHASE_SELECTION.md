# TAT-T Crystal: выбор фаз через сеточное сканирование

## Обзор
TAT-T Crystal — трёхслойная архитектура (ДНК/РНК/Белок) с настраиваемыми фазовыми сдвигами. В этом документе представлены результаты сканирования фазового пространства.

## Методология
- **Архитектура:** головы 3/5/11.
- **Сканирование:** сетка 4×4×4 (64 комбинации), фазы 0.00–0.15 шаг 0.05.
- **Обучение:** 30 эпох на комбинацию.
- **Данные:** комбинированный поток (142 шага) из Resonance-Missile, Cophy, Agora/mnemo.
- **Оборудование:** NVIDIA T4 GPU, время ~2ч05м.
