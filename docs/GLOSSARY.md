# TAT Glossary

| Term | Definition |
|------|------------|
| **Adaptive Anchors** | Algorithm that finds structural minima in a 1D series without training. |
| **TAT-Monitor** | Anomaly detector based on `div - harm` decomposition over sliding windows. |
| **Coherence** | Complex similarity measure between two vectors, computed as `|⟨c1,c2⟩|/(‖c1‖·‖c2‖)` with `c = x + i·x·sin(1.987)`. |
| **Triadic Agreement** | Product of three normalized metrics (coarse, fine, error), measuring structural convergence. |
| **Moiré Interference** | Multi-stream phase-shifted superposition revealing hidden periodicities. |
| **Sultanov Silence** | Complete absence of triadic resonance on prime-numbered quantum spin chains under symmetric defect placement. |
| **Block-Shuffle** | Permutation method preserving local dependence by shuffling blocks of consecutive samples. |
| **θ (Theta)** | Phase constant of TAT: 1.987. |
| **SABBATH** | TAT's silence mode: returns no answer when coherence < 0.3. |
| **Open-Core** | Business model where core features are open-source, advanced features are commercial. |
