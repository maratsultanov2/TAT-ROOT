# TAT-T Crystal 在金融数据中的应用 — 自适应相位

**状态:** 已验证 — 实证案例研究。

## 概述

本文档展示了 TAT-T Crystal 在金融时间序列上的应用案例。模型仅使用三只股票（AAPL、MSFT、GOOGL）的价格数据来预测市场波动率。与之前基于 LLM 数据的基准测试不同，本案例展示了 TAT 适应噪声高频数值流的能力。

## 架构与设置

- **层:** DNA（3 头）、RNA（5 头）、Protein（11 头）— 共 19 头。
- **参数:** ~1.94M (FP32)，内存占用 ~7.75 MB。
- **相位:** 可学习（自适应）— 初始化为 (0.00, 0.15, 0.15)。
- **训练:** 300 个周期，Adam lr=1e-3，损失 = MSE(发散, 波动率) + 0.1×和谐度。
- **硬件:** NVIDIA T4 GPU，运行时间约 5–7 分钟。

## 数据与目标

- **来源:** Yahoo Finance（90 天，AAPL、MSFT、GOOGL 每日收盘价）。
- **特征:** 3 维价格向量。
- **目标:** 归一化 5 日滚动波动率（标准差/平均值）。

## 结果

| 指标 | 值 |
|---|---|
| 相关性（发散 vs 波动率） | **0.952** |
| 平均发散 | 0.402 |
| 在 0.3–0.5 区间内的比例 | 37.1% |
| >0.5 的比例 | 32.3% |
| 最终相位 | DNA=0.000, RNA=0.150, Protein=0.147 |

该模型以高保真度学会了跟踪波动率。Protein 相位从 0.150 略微移至 0.147，表明系统根据数据结构进行了自我校准。
